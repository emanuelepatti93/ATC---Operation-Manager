# ATC---Operation-Manager

Gestionale operativo per la gestione turni, presenze, posizioni, report e riepiloghi.

## Struttura del progetto

- `main.py`: punto di avvio dell'applicazione
- `app/`: codice sorgente principale
- `app/config/`: configurazioni
- `app/controllers/`: logica di controllo
- `app/core/`: componenti centrali dell'app
- `app/database/`: accesso e gestione dati
- `app/dialogs/`: finestre di dialogo
- `app/models/`: modelli dati
- `app/resources/`: risorse dell'app
- `app/services/`: servizi applicativi
- `app/ui/`: componenti interfaccia grafica
- `app/utils/`: utilità e helper
- `app/windows/`: finestre principali
- `database/`: database locali o file di supporto
- `docs/`: documentazione
- `reports/`: report esportati
- `resources/`: immagini, icone e asset
- `tests/`: test automatici
- `backups/`: copie di backup del progetto

## Avvio

```bash
pip install -r requirements.txt
python main.py
```
